尺寸公式用 cqi 而非 100%。--tile 会同时被瓦片的 width、height 和牌堆 min-height 消费，若用百分比会形成循环依赖——本档实测复现过牌堆塌成 0 高、瓦片全部消失。cqi 是确定长度，无循环。老浏览器回退见规格文档 §3.1。
为什么不用 filter: brightness()/blur() 当主手段：每张牌一个 filter 会各建一个合成层，40 张牌在千元安卓机上会掉到 45fps 以下。--cover 遮罩只是一个 opacity 过渡，走合成器，几乎零成本。filter 已降级为桌面可选增强（.quality-high）。
